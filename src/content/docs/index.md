## Using an agent?

Give your agent this URL:

```
https://docs.pmservers.org/llms.txt
```

It lists every page as a raw Markdown file. All pages in one file are at `https://docs.pmservers.org/llms-full.txt`. See [For agents](/agents/).

## Addresses

| What | Address |
|---|---|
| Console | `https://console.pmservers.org` |
| AI API (OpenAI-compatible) | `https://api.pmservers.org/ai/v1` |
| Object storage (S3 API, path style, region `pms`) | `https://s3.pmservers.org` |
| Management API | `https://api.pmservers.org/v1` |
