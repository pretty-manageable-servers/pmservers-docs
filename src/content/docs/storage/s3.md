PMS Cloud storage is S3-compatible. You make buckets and storage keys in the console. Then you use any S3 SDK or tool.

## Upload size: 100 MB for each request

S3 traffic goes through Cloudflare. **Cloudflare rejects a request body larger than 100 MB.**

For files larger than 100 MB, use multipart upload. Most S3 SDKs and tools do this automatically:

| Tool | Behavior |
|---|---|
| AWS CLI (`aws s3 cp`) | Multipart for files over 8 MB by default. |
| boto3 `upload_file` | Multipart for files over 8 MB by default. |
| AWS SDK for JavaScript v3 | Use `Upload` from `@aws-sdk/lib-storage`. A plain `PutObject` does not split the file. |
| rclone | Multipart by default. |

Keep each part at 100 MB or less.
