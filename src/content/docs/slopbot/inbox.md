Each member has an inbox in each server. An inbox item is a short summary that Slopbot writes. Each item links to its source messages.

## Add an item

Ask Slopbot to put a message in a member's inbox. For example, ask it to put this in `@name`'s inbox.

- Any member can add items for any member of the server.
- Each member can add 20 items a day.
- An item shows only if the member can see the channel of its source messages.
- Items are deleted 30 days after they are made.

## Read your inbox

- Run `/inbox`. Only you see the reply.
- Open the Inbox tab in the [web console](/slopbot/web-console/).
- Ask Slopbot, "what is in my inbox?"

## Mark items done

Run `/inbox done:` with the item IDs, or with `all` to mark every item.
