Slopbot is a general-purpose intelligence. It is a team player in Discord. When monitoring is on, it follows the conversation in a channel and joins in when it can help. You do not need to ping it or use a command.

Where ideas bloom.

## What Slopbot does

- Answers questions in a channel.
- Searches the web. Results give the URL of each source.
- Searches the message history of a channel and shows the source messages.
- Reads files and images that people share.
- Runs commands and code in a sandbox.
- Saves statements from your team as memories. Each memory links to its source message.
- Sets reminders, manages tasks and runs polls.
- Runs long work in a task thread.

## How Slopbot joins a conversation

| You do this | Slopbot does this |
|---|---|
| Mention Slopbot | Answers. |
| Reply to a Slopbot message | Answers. |
| Write in a channel with monitoring on | Reads the message. It joins in when it judges it can help. |
| Mention Slopbot with `!task` and a goal | Starts a task thread. The thread keeps its own conversation. |

A server admin turns on monitoring and adds each channel. Without monitoring, Slopbot answers only when you mention it or reply to it.

One Slopbot serves many Discord servers. Each server has its own settings, channels and tools.
