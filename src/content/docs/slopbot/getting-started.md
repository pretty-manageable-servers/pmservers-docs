## Add Slopbot to a server

You need the Manage Server permission in the server to add Slopbot.

1. Get the Slopbot invite link from your PMServers team. The **Add to Discord** button on the Slopbot page does not have an invite link yet.
2. Open the invite link. Choose your server.
3. Allow these permissions:
   - View Channels
   - Send Messages
   - Read Message History
   - Create Public Threads
   - Send Messages in Threads
   - Add Reactions. This one is optional. Slopbot needs it only for emoji reactions.
4. Add each channel that Slopbot reads and answers in. A server admin does this in **Channels & history** in the [web console](/slopbot/web-console/#settings).

To test Slopbot, mention it in a channel it can read:

```text
@Slopbot what can you do?
```

## Sign in to the web console

1. Open https://slopbot.pmservers.org/console.
2. Select **Sign in with Discord**.
3. Approve the Discord sign-in.

You can sign in only if you are in a Discord server that has Slopbot. If you are not, the console shows "Slopbot is not in your servers."

If you are in more than one server with Slopbot, choose the server you want first. Server settings apply only to the server you choose.
